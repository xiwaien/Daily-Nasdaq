# 美股纳斯达克与核心科技股每日投研与宏观监测库

本仓库聚焦**纳斯达克四大基准指数**、**19 家美股核心科技企业**、**15 项跨资产市场情绪指标**与**美国国债长短期期限利差**的自动化跟踪。全套算法遵循三大准则：

1. **纯正中文母语语序**：所有报告、图表与交互看板均按自然中文逻辑排版，摒弃生硬直译与中英混杂抬头。
2. **零小道消息（纯官方信源）**：政策与经贸资讯仅采信美联储、纽约联储、美国财政部、经济分析局、商务部工业与安全局、贸易代表办公室及美国证监会（`8-K` / `425`）具有法律效力的一手文件。
3. **初学者的术语通俗伴读**：自动识别正文专业名词并附通俗解释与实战意义；已掌握词汇可通过配置文件永久免除重复解释。

## 二、如何直接打开交互式看板页面（无需看代码）

在 GitHub 代码列表直接点开 `.html` 文件默认只会显示源码，可通过以下三种方式直接浏览完整交互页面：

1. **GitHub Pages 在线门户（推荐）**：仓库已内置 `.github/workflows/deploy-pages.yml` 自动网页编译工作流。首次只需在 GitHub 仓库顶部进入 **Settings → Pages → Build and deployment → Source 选择 `GitHub Actions`**，即可永久通过 **`https://xiwaien.github.io/Daily-Nasdaq/`** 在线浏览（每日推送后自动编译刷新）。
2. **Antigravity 对话右侧面板直看**：每日自动任务运行完毕后，会自动将最新看板编译为对话内原生交互页面（点击回复中的看板卡片即可在右侧直接交互）。
3. **本地电脑双击打开**：在资源管理器双击打开 `交互式看板/index.html`，即可在浏览器中自由切换各日期科技股看板与美债期限利差看板。
