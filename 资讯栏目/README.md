# 官方宏观与国际经贸资讯专栏（杜绝小道消息）

本目录专门存放每日自动抓取并提炼为**纯正中文语序**的官方宏观、货币政策、国际贸易关系及核心科技公司法定披露汇编。

## 信息收录铁律

1. **只采信官方一手权威信源，零小道消息**：
   - **美元利率与货币政策**：美联储理事会（FOMC 利率决议声明、会议纪要、理事正式演讲稿）、纽约联储（EFFR 联邦基金有效利率、SOFR 担保隔夜融资利率）、欧洲中央银行货币政策公报。
   - **宏观经济与财政数据**：美国经济分析局（GDP 国内生产总值、PCE 个人消费支出物价指数、国际贸易收支）、美国劳工统计局（非农就业与 CPI 消费者物价指数）、美国财政部国债利率数据。
   - **国际贸易关系与技术管制**：美国联邦公报（Federal Register 法定行政法规）、美国贸易代表办公室（USTR 301 条款关税、双边及多边贸易协定执行公告）、美国商务部工业与安全局（BIS 出口管制规则与实体清单法定文件）。
   - **上市公司法定重大事项**：美国证券交易委员会（SEC EDGAR）由上市公司正式签署提交的 `Form 8-K` 与 `Form 6-K` 具有法律约束力的重大事项披露。
2. **严禁收录**：匿名知情人士爆料、社交媒体传言、未经证实的供应链砍单猜测、做空机构单方面指控或卖方分析师小道传闻。
3. **纯正中文语序与新手术语伴读**：所有外文官方公报均按中文母语逻辑重组提炼（先背景与主体、再核心举措、后市场传导影响），并自动识别文中初学者可能陌生的专业名词予以通俗解释（读取根目录 `../术语配置.json` 中的免解释清单）。

## 文件命名规范

- `YYYY-MM-DD_官方宏观与政策资讯.md`：当日中文精炼版官方资讯与新手术语解读。
- `YYYY-MM-DD_官方信源原始快照.json`：当日脚本实时采集的各部委、央行与美国证监会法定接口原始结构化存档，便于溯源核验。
